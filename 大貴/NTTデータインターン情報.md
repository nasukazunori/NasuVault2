# NTTデータインターン情報

大貴が合格した「現場受け入れ型」インターンの案件詳細（プロジェクト紹介資料より）。企業研究は[[NTTデータ企業研究]]を参照。

## コース概要
- **コース名**：データサイエンティストコース
- **案件コード**：公社基-39（＝公共・社会基盤セグメントの案件）
- **テーマ**：「AI×可視化ツールでデータ活用！データ開発〜データ分析までを体験してみよう！」

## 受入れ条件
| 項目 | 内容 |
|---|---|
| 受入れ期間 | 2026年8月1日（土）〜9月30日（水）の期間内で日程調整 |
| 受入れ日数 | 5日間 |
| 勤務場所 | NTTデータ品川ビル（アレア品川） |
| 必須スキル | PCおよびOfficeが使用できること |
| あると望ましいスキル | データ活用への関心／新しい技術への関心／何らかのプログラミング経験（レベル不問） |

## テーマ詳細
企業でのAI／データ活用が加速し、その源泉であるデータの重要性は増している。本プロジェクトでは、データの取り込み（アプリケーション開発）からデータの可視化・分析まで、データ活用の上流〜下流を実際に自分の手を動かして体験する。
- クラウド環境でのデータ取り込み開発
- データの抽出／可視化による分析
- データ分析の基礎知識習得

## アピールポイント（企業側メッセージ）
- 企業でのデータ活用を上流〜下流までトータルで支援する、NTTデータのビジネスの一端を経験できる貴重な機会
- 社員訪問の機会を多く設定予定。若手社員による配属相談や、仕事の良いところ・大変なところなどリアルな声も届けてもらえる予定
- トレーナーは2年目社員

## 大貴の強みとの接続
- 統計検定2級・基本情報技術者で培ったデータ分析の基礎知識が、コース内容（データ抽出〜可視化〜分析）と直接合致する
- ベイスターズのインターンで実施したアンケート分析（クロス分析・相関分析）の経験を、実務での「データ取り込み〜可視化」体験と接続して語れる
- [[NTTデータ企業研究]]の「公共・社会基盤」セグメント（案件コード「公社基」）が今回の配属領域である点を踏まえ、官公庁・自治体・インフラ関連のデータ活用事例を事前に押さえておくと当日の議論で深みが出る
