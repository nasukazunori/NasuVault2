# 公認会計士を中途採用している企業の調査（2026/09/18）

[[公認会計士vs簿記1級（ガクチカ戦略）]]の裏付けとして、
「公認会計士を中途で採用している企業＝会計士資格を評価する社風」という仮説を検証するため、
指定企業＋自主調査した企業を調べた。

## 調査対象企業（指定分）

| 企業 | CPA中途採用の実態 |
|---|---|
| 三井住友信託銀行 | 弁護士・会計士等の専門家と連携し、信託機能を使った資金調達・投資ストラクチャー組成、新商品開発の業務あり。中途採用比率43% |
| 三菱UFJ信託銀行 | **公認会計士・税理士・簿記1級保有者**を対象に、経営企画部主計グループでの決算・制度対応業務を募集（年収500〜800万）。中途採用比率49%。CPAと簿記1級を同一求人で並記している点が重要 |
| KDDI | 経理職（グループ会社経理、CFO補佐等）で中途採用を積極実施。マイナビ会計士に求人掲載あり |
| 日立製作所 | 財務統括本部（経理部／財務戦略部）で公認会計士資格が求められる中途ポジションあり（M&A、連結決算、税務、管理会計） |
| りそな銀行 | 内部監査職で会計事務所出身者歓迎（年収800〜1500万）。埼玉りそなは公認会計士協会と提携し取引先への会計士人材紹介も実施 |
| みずほFG | グループ合同採用。会計士向け求人は複数エージェント経由で存在（非公開求人が多い） |
| 日本政策金融公庫 | 法律・会計関連職として公認会計士を含む中途採用を随時実施。中小企業融資審査＝財務分析力が直結 |
| デロイトトーマツFAS | FAS・M&Aコンサルタント職（年収750〜1800万）。公認会計士は歓迎資格。監査法人・投資銀行等での実務経験3年以上が基本要件だが、資格保有者はポテンシャル採用の余地あり |
| 芙蓉総合リース（ふそうリースと混同注意） | 中途（キャリア採用）で経理関連職を募集。CPA限定求人は他社より薄め |

### 総評
三菱UFJ信託銀行が象徴的で、CPA・税理士・簿記1級を**同一求人で並列要件**にしている。
実務現場は「合格の有無」より「その水準の会計知識があるか」を見ている証拠であり、
簿記1級を前面に出す戦略の妥当性を裏付ける。

## 自主調査：信吾の強み（企業分析×財務会計×法律、独学での高難度資格挑戦）が活きそうな企業

- **日本政策投資銀行（DBJ）**：プロジェクトファイナンス・事業再生ファイナンス・M&A関連投融資が中核。「ゼネラリストを超えたスペシャリスト」育成方針で会計・法律の複合知が評価されやすい
- **オリックス**：法人金融・事業投資・リース等の金融コングロマリット。経理・財務職ではUS CPA／日本公認会計士／税理士資格保有者を明確に歓迎と明記
- **日本銀行**：新卒採用職種に「会計・税務（公認会計士）」が独立カテゴリとして存在。考査局・金融機構局等の企業審査・金融システム分析業務と親和性が高い
- **総合商社（三菱商事・伊藤忠等）**：経営企画・事業投資先管理・CFO室で会計士有資格者が多数活躍。新卒配属は狭き門だが「企業分析への関心」というストーリーは事業投資判断業務と相性良好
- **格付機関（R&I／JCR）**：発行体企業の財務分析・信用力評価が本業そのもの。法律（契約・スキーム理解）と会計（財務諸表分析）の両方が必須で、最も直接的に強みが活きる業種の一つ
- **生命保険会社の資産運用部門（日本生命・第一生命等）**：投融資先の与信・財務分析、私募社債・プロジェクトファイナンスの審査に会計知識が必須
